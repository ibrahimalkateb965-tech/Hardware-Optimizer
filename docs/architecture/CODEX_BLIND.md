## 1. Architectural Philosophy: The "Air-Gapped" Safety Pipeline

The primary danger in automated hardware optimization tools is the combination of web exposure and administrative privileges. A flawed design could allow Cross-Site Scripting (XSS) or Localhost Command Injection to escalate into kernel-level configuration corruption.

Codex proposes a **Three-Stage Isolated Pipeline**:

```
[ Web UI (Untrusted) ] 
       │ (REST / Localhost Only + Session Bearer Token)
       ▼
[ FastAPI Orchestrator (Standard User Context) ]
       │ 
       ├─► [ Deterministic Rules Engine (Pure Function: Inventory -> Allowlisted Candidates) ]
       ├─► [ LLM Explainer Client (GLM-5.3-Flash via OpenCode Go: Rank & Translate Only) ]
       │ 
       ▼ (HMAC-SHA256 Signed Execution Ticket)
[ Elevated Helper Execution Daemon (Admin / UAC On-Demand) ]
       │ 
       ├─► Pre-Execution: Windows VSS System Restore Point
       ├─► Atomic Execution: Direct binary execution (NO cmd.exe / powershell.exe string interpolation)
       └─► State Ledger: SQLite WAL + Immutable JSON rollback manifests
```

## 2. Core Architectural Challenges & Codex Mandates

### Challenge 1: WMI/CIM Query Hangs & Provider Timeouts
* **Defect in naive designs:** Standard `Get-CimInstance` queries against `root\wmi` (e.g., `MSAcpi_ThermalZoneTemperature`) or `Get-StorageReliabilityCounter` can block execution threads for 30+ seconds if driver providers are unresponsive or uncooperative.
* **Codex Mandate:** All hardware collectors **MUST** execute under strict 3.0-second async threadpool timeouts. If a provider fails to return within 3000ms, the collector must immediately emit a structured `UnsupportedHardwareMetric` fallback without halting the orchestrator.

### Challenge 2: Trust Boundary Between UI and Elevated Helper
* **Defect in naive designs:** Passing command arguments or script paths directly to an elevated helper creates a local privilege escalation (LPE) vector.
* **Codex Mandate:**
  1. The elevated helper must never accept raw commands, script paths, or executable paths from the frontend or backend.
  2. The helper must contain a **hardcoded, static dispatch table** of enum IDs (e.g., `ActionID::STORAGE_ENABLE_TRIM`).
  3. The request must be passed via a cryptographically bound ticket:
     $$\text{Ticket} = \{\text{session\_id}, \text{action\_ids}, \text{timestamp}, \text{nonce}\} \quad \text{signed with ephemeral secret}$$
  4. The helper executes exact system binaries (e.g., `C:\Windows\System32\fsutil.exe`) directly via `CreateProcessW` without invoking `cmd.exe /c` or PowerShell script evaluators.

### Challenge 3: Reboot-Resilient Rollback State Engine
* **Defect in naive designs:** Optimizations requiring a system restart (e.g. HAGS `HwSchMode`) lose in-memory rollback state if the system crashes or restarts.
* **Codex Mandate:**
  1. Every session generates an on-disk transaction manifest: `sessions/<session_id>/manifest.json`.
  2. For Tier 2 changes requiring reboot, state is marked `STATE_APPLIED_AWAITING_REBOOT`.
  3. A lightweight Windows Task / RunOnce sentinel verifies post-boot health. If boot fails or user triggers emergency recovery, `python -m optimizer rollback --session latest` reads the immutable manifest and restores original values.

### Challenge 4: Zero-Trust LLM Output Ingestion
* **Codex Mandate:**
  1. The LLM output is treated as untrusted text.
  2. The backend validates the response against a strict Pydantic model:
     - `action_id`: Must exist in `CandidateActions` generated by the rules engine.
     - `priority`: Integer (1..10).
     - `rationale_arabic`: String (max 500 chars, stripped of control characters).
  3. Any recommendation returned by the LLM that was not originally in the Candidate list is silently dropped.

## 3. Technology Stack Recommendations

* **Backend:** Python 3.12 + FastAPI + Pydantic v2 + `psutil` + `pywin32` (for direct Win32 API calls where WMI is slow).
* **Database:** SQLite in WAL mode (`PRAGMA journal_mode=WAL;`), enforcing ACID guarantees for state backups.
* **Frontend:** Vite + React + TypeScript + Tailwind CSS. Pre-bundled static SPA served directly by FastAPI to avoid multi-port CORS vulnerabilities.
